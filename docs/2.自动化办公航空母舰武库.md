## 一、双引擎架构：ImgClickFlow + Playwright

首先再次强调：ImgClickFlow 不是万能的，Playwright 也不是。**两者结合，几乎覆盖所有自动化场景**。

### 1.1 双剑合璧的职责分工

| 操作对象 | 推荐引擎 | 原因 |
|:---|:---|:---|
| 桌面软件（ERP、财务软件、设计工具） | ImgClickFlow | Playwright 无法操作桌面软件 |
| 远程桌面 / 虚拟机 | ImgClickFlow | Playwright 无法穿透远程桌面 |
| 历史遗留工业软件（无 UI 自动化接口） | ImgClickFlow | 只能通过图像识别操作 |
| Web 页面（标准浏览器） | Playwright | 元素定位更精准，能读 DOM，能等待元素状态 |
| Web 页面上有多个相同按钮 | Playwright | 可通过上下文定位，ImgClickFlow 全屏搜索可能点错 |
| 需要提取网页表格数据 | Playwright | 直接读取 DOM，ImgClickFlow 只能截图，无法提取数据内容 |
| 页面加载慢，按钮不可点击 | Playwright | 可检测元素 disabled 属性，自动等待变为可用 |
| 下拉列表有 100 个选项 | Playwright | `page.select_option()` 直接选中，ImgClickFlow 需截图+滚动+匹配 |
| 跨浏览器兼容性 | Playwright | 自动安装和管理所有浏览器，ImgClickFlow 需为每个浏览器重做模板截图 |
| 混合流程（Web → 桌面 → Web） | 两者配合 | Playwright 管 Web 段，ImgClickFlow 管桌面段 |

### 1.2 双引擎协作示例

```python
from imgclickflow import auto
from playwright.sync_api import sync_playwright

# Playwright 负责 Web 操作
with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com/report")
    page.click("text=下载报表")
    page.wait_for_selector("text=下载完成")
    browser.close()

# ImgClickFlow 负责桌面操作
auto.click("文件夹图标")
auto.write("C:\\下载\\报表.xlsx")
auto.press("enter")
auto.wait("文件已打开")
auto.click_robust("打印按钮")
```

### 1.3 学习建议

1. **先学 ImgClickFlow**：如果目标包含任何非 Web 软件，ImgClickFlow 是必须的。链式调用 10 分钟即可上手。
2. **再学 Playwright**：如果流程中有 Web 页面操作，Playwright 能大幅提升稳定性和效率。学习时间约 2-3 小时。虽然 ImgClickFlow 也能覆盖 Web 场景，但一些场景下的易用性不如 Playwright 直接操作 Web。
3. **两者不是替代关系，是互补关系**。ImgClickFlow 无法替代 Playwright 的 DOM 读取能力，Playwright 无法替代 ImgClickFlow 的桌面图像识别能力。


## 二、核心定位

| 工具 | 定位 | 优势 |
|:---|:---|:---|
| **ImgClickFlow** | 图形驱动自动化引擎 | DPI 自适应、鲁棒点击、调试录像、零学习成本的链式调用 |
| **Python 生态** | 万能后台任务航空母舰 | 数据库、API、数据处理、文件操作、AI，任何需求都有成熟库 |
| **两者结合** | 完整的桌面自动化方案 | 前端 GUI 操作用 ImgClickFlow，后端数据处理用 Python 库 |

商业 RPA 的策略是"把所有能力内置于一个平台"。ImgClickFlow 的策略是"**把图形驱动做到极致，把后台能力交给 Python 生态**"。

### 📁 文件与路径操作

#### os / shutil — 文件批量操作（含 glob 查找）

**推荐星级**：★★★★☆ 　 **学习时间**：10 分钟

**主要功能**：

| 功能 | 说明 | 典型用法 |
|:---|:---|:---|
| 遍历文件夹 | 获取所有文件名 | `os.listdir(path)` |
| 文件重命名 | 批量改名 | `os.rename(old, new)` |
| 文件复制/移动 | 整理归档 | `shutil.copy(src, dst)` / `shutil.move(src, dst)` |
| 创建/删除文件夹 | 目录管理 | `os.makedirs(path)` / `os.rmdir(path)` |
| 获取文件信息 | 大小、修改时间 | `os.path.getsize(path)` / `os.path.getmtime(path)` |
| 路径拼接 | 跨平台路径处理 | `os.path.join(folder, filename)` |
| 通配符查找 | 找特定类型文件（配合 glob） | `glob.glob("*.xlsx")` |

**推荐理由**：10 分钟学会，立竿见影。每天手动整理文件、重命名、归档，不如一行 Python 搞定。**这是自动化小白的第一个"哇塞"时刻**——原来电脑可以自己帮你理文件。

> ImgClickFlow 已内置文件查找功能，但 os + glob 的组合在纯数据处理脚本中更轻量，适合批量改名、按类型归档等批量操作。

```python
import os
import shutil
import glob

# 将所有 PDF 移动到"归档"文件夹
for filename in os.listdir("下载"):
    if filename.endswith(".pdf"):
        shutil.move(f"下载/{filename}", f"归档/{filename}")

# 批量重命名：给所有截图加上日期前缀
for f in glob.glob("截图*.png"):
    os.rename(f, f"20260509_{f}")
```

### 📅 日期时间

#### datetime — 日期计算与格式化

**推荐星级**：★★★★☆ 　 **学习时间**：10 分钟

**主要功能**：

| 功能 | 说明 | 典型用法 |
|:---|:---|:---|
| 获取当前时间 | 脚本标配 | `datetime.datetime.now()` |
| 格式化输出 | 用于文件名 | `.strftime("%Y%m%d_%H%M%S")` |
| 时间加减 | 计算截止日 | `+ timedelta(days=30)` |
| 日期比较 | 判断是否过期 | `date1 < date2` |
| 解析字符串 | 文字转日期对象 | `datetime.datetime.strptime(s, "%Y-%m-%d")` |

**推荐理由**：几乎所有自动化脚本都需要日期——给文件加时间戳、计算报表周期、判断有效期。10 分钟学会，每个脚本都会用到。配合 os 和 time，你已能完成大部分文件整理类的自动化需求。

```python
import datetime

now = datetime.datetime.now()
filename = f"日报_{now.strftime('%Y%m%d_%H%M%S')}.xlsx"

# 计算截止日期（30天后）
deadline = now + datetime.timedelta(days=30)
```


### 📊 Excel / 表格处理

#### pandas — 数据处理之王

**推荐星级**：★★★★★ 　 **学习时间**：1-2 小时

**主要功能**：

| 功能 | 说明 | 典型用法 |
|:---|:---|:---|
| 读取 Excel/CSV | 一行代码读取整个工作表 | `pd.read_excel("数据.xlsx")` |
| 写入 Excel/CSV | 处理完的数据直接导出 | `df.to_excel("结果.xlsx", index=False)` |
| 数据筛选 | 按条件过滤行 | `df[df["金额"] > 1000]` |
| 分组汇总 | 按类别求和、求平均 | `df.groupby("部门")["金额"].sum()` |
| 透视表 | 多维度交叉统计 | `pd.pivot_table(df, values="金额", index="月份", columns="产品")` |
| 合并表格 | 多表关联（VLOOKUP 替代） | `pd.merge(df1, df2, on="编号", how="left")` |
| 去重、排序、填充空值 | 数据清洗 | `df.drop_duplicates()` / `df.sort_values()` / `df.fillna(0)` |

**推荐理由**：办公室里 80% 的自动化需求都和表格数据有关。pandas 用一两行代码就能完成手工操作半小时的筛选汇总工作。**这是从"会点鼠标"到"会写自动化"最关键的一步。** 学完它，你已经能处理大部分数据报表类的自动化需求。

```python
import pandas as pd

# 读取销售数据，按产品汇总，导出结果
df = pd.read_excel("销售明细.xlsx")
summary = df.groupby("产品名称")["金额"].sum().sort_values(ascending=False)
summary.to_excel("销售汇总.xlsx")
```

**推荐星级**：★★★★★ 　 **学习时间**：30 分钟

```python
wb = Workbook()

wb.save("销售报表_格式化.xlsx")
```

**推荐星级**：★★★★☆ 　 **学习时间**：30 分钟

### 📁 现代化路径操作

#### pathlib — 面向对象的路径操作

**推荐星级**：★★☆☆☆ 　 **学习时间**：20 分钟

**主要功能**：

| 功能 | 说明 | 典型用法 |
|:---|:---|:---|
| 路径对象 | 面向对象的路径 | `Path("folder/file.txt")` |
| 自动跨平台 | Windows/Linux 斜杠自动处理 | `Path("data") / "2026" / "report.xlsx"` |
| 读写文件 | 直接读文本 | `Path("file.txt").read_text()` |
| 判断文件存在 | 操作前检查 | `path.exists()` |
| 创建目录 | 自动创建父目录 | `path.mkdir(parents=True)` |

**推荐理由**：os.path 的现代化替代品，代码更优雅。非必学（os.path 完全够用），但如果追求代码整洁度，值得了解。


### 🌐 网络请求

#### requests — HTTP 请求与 API 调用

**推荐星级**：★★★★☆ 　 **学习时间**：30 分钟

**主要功能**：

| 功能 | 说明 | 典型用法 |
|:---|:---|:---|
| GET 请求 | 获取网页或 API 数据 | `requests.get(url)` |
| POST 请求 | 提交表单数据 | `requests.post(url, json=data)` |
| 带认证的请求 | API Token 认证 | `headers={"Authorization": "Bearer xxx"}` |
| 下载文件 | 从 URL 下载 | `r.content` 写入文件 |
| 解析 JSON | API 返回转字典 | `r.json()` |
| 超时与重试 | 网络不稳定处理 | `timeout=10` |

**推荐理由**：越来越多公司的业务系统提供 API 接口。学会 requests，可以直接从系统取数据而不需要手动导出，可以把处理结果自动提交回去。这是"自动化脚本"升级为"自动化系统"的关键一跃。

```python
import requests

r = requests.get("https://api.example.com/data?date=today",
                 headers={"Authorization": "Bearer your_token"})
data = r.json()
print(f"获取到 {len(data)} 条记录")
```


### 📧 邮件收发

#### smtplib / imaplib — 邮件自动收发

**推荐星级**：★★★☆☆ 　 **学习时间**：30 分钟

**主要功能**：

| 功能 | 说明 | 典型用法 |
|:---|:---|:---|
| 发送邮件 | 自动发送通知、日报 | `smtplib.SMTP_SSL()` |
| 带附件发送 | Excel 报表、截图 | `MIMEMultipart()` |
| HTML 邮件 | 格式化正文 | `MIMEText(html, "html")` |
| 读取邮件 | 自动检查收件箱 | `imaplib.IMAP4_SSL()` |
| 按主题筛选 | 只处理特定邮件 | `search(None, 'SUBJECT "日报"')` |

**推荐理由**：自动化流程的最后一公里——处理完的数据用邮件自动发送给领导或同事。一次配置，每天的日报/周报自动发，不再需要手动粘贴附件点发送。

```python
import smtplib
from email.mime.text import MIMEText

msg = MIMEText("今日巡检已完成，共处理15项任务。")
msg["Subject"] = "巡检报告"
msg["From"] = "you@email.com"
msg["To"] = "manager@email.com"

with smtplib.SMTP_SSL("smtp.qq.com", 465) as server:
    server.login("you@email.com", "授权码")
    server.send_message(msg)
```


### 🗄️ 数据库操作

#### sqlite3 — 本地轻量数据库

**推荐星级**：★★★☆☆ 　 **学习时间**：30 分钟

**主要功能**：

| 功能 | 说明 | 典型用法 |
|:---|:---|:---|
| 创建数据库 | 本地单文件数据库 | `sqlite3.connect("data.db")` |
| 执行 SQL | 增删改查 | `conn.execute("SELECT ...")` |
| 事务管理 | 批量操作 | `conn.commit()` |

**推荐理由**：Python 自带，无需安装任何服务端。适合需要存储历史数据、查询比 Excel 快、数据量超过 Excel 承载上限的个人项目。比 pymysql 更适合小白——不需要申请数据库权限，不需要知道服务器地址。

```python
import sqlite3

conn = sqlite3.connect("records.db")
conn.execute("CREATE TABLE IF NOT EXISTS logs (date TEXT, status TEXT)")
conn.execute("INSERT INTO logs VALUES ('2026-05-09', '完成')")
conn.commit()
results = conn.execute("SELECT * FROM logs").fetchall()
conn.close()
```


#### pymysql — 连接 MySQL 数据库

**推荐星级**：★☆☆☆☆ 　 **学习时间**：30 分钟

**主要功能**：

| 功能 | 说明 | 典型用法 |
|:---|:---|:---|
| 连接远程数据库 | 连公司 MySQL 服务器 | `pymysql.connect(host=..., user=..., password=...)` |
| 执行 SQL | 查询业务数据 | `cursor.execute(sql)` |
| 事务提交 | 写入操作 | `conn.commit()` |

**推荐理由**：如果你所在的公司有专门的数据团队维护数据库，且你有只读权限，pymysql 可以让你的自动化脚本直接从数据库取数据——不需要手动导出 Excel 再处理。但大多数办公室职员接触不到数据库服务器，优先级较低。

```python
import pymysql

conn = pymysql.connect(host="192.168.1.100", user="readonly",
                       password="password", database="erp_db")
cursor = conn.cursor()
cursor.execute("SELECT * FROM orders WHERE date = '2026-05-09'")
rows = cursor.fetchall()
conn.close()
```


#### sqlalchemy — 数据库 ORM 框架

**推荐星级**：★☆☆☆☆ 　 **学习时间**：2-3 小时

**主要功能**：

| 功能 | 说明 | 典型用法 |
|:---|:---|:---|
| ORM 映射 | 表→类，行→对象 | `class Order(Base)` |
| 多数据库支持 | MySQL/SQLite/PostgreSQL 统一接口 | `create_engine("mysql://...")` |
| pandas 集成 | 直接 `df.to_sql()` | `df.to_sql("orders", engine)` |

**推荐理由**：功能强大，但学习曲线陡峭。适合有大量数据库操作需求的复杂项目。小白阶段不需要学，到了"进阶"阶段再回头看。
